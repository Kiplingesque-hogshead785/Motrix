## 🔧 How to Use Motrix (Quick Start Guide)

Using Motrix is as easy as 1-2-3:

### 1. Download a File (Normal Link)

- Copy any download link from your browser.
- Open Motrix and click the **"+"** button (or press `Ctrl+V`).
- The link is automatically detected. Click **"Start"** to begin.

### 2. Download a Torrent or Magnet Link

- Click the **torrent icon** (looks like a magnet) in Motrix.
- Choose your `.torrent` file, or paste a magnet link directly.
- Select where to save the file and click **"Start."**

### 3. Manage Your Downloads

- **Pause/Resume:** Click the pause or play button next to any download.
- **Speed Limit:** Go to Settings to set a maximum speed if needed.
- **File Location:** Every download is saved to your "Downloads" folder by default.
